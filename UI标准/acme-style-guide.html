01概述 Overview

本风格指南定义了 Acme Inc. 着陆页项目的完整设计系统。该项目采用 扁平化设计语言 (Flat Design)，以干净、现代的视觉风格为核心，强调清晰的层级结构、一致性的间距节奏和精心调配的配色方案。

设计原则

原则说明
清晰至上每个区块有明确的视觉层级，标题 → 副标题 → 正文 → 辅助信息层层递进
一致性间距遵循 4px/8px 基础网格，圆角、阴影、动画时间函数全站统一
色彩语义化蓝色 = 主品牌/交互，绿色 = 成就/成功，橙色 = 行动/能量，灰度 = 层级
响应式优先桌面优先设计，768px 断点以下自动适配移动端

技术栈

项目选型
字体Inter (Google Fonts) — weights: 400, 500, 600, 700, 800
图标内联 SVG (Material Design icons path)
CSS 架构纯 CSS 变量系统 (:root)，BEM-like 类命名
布局CSS Grid + Flexbox 混合布局
响应式单断点 @media (max-width: 768px)
浏览器前缀-webkit-backdrop-filter, -webkit-font-smoothing, -webkit-text-size-adjust

03排版 Typography

字体栈

'Inter', ui-sans-serif, system-ui, sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"
